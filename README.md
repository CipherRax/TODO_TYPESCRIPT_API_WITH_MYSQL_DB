# TypeScript Todo API (MySQL Backend)

A robust, production-ready RESTful API built with **Node.js**, **Express**, and **TypeScript**, featuring a persistent **MySQL** database integration.

## 🚀 Features
- **Full CRUD operations**: Create, Read, Update, and Delete todos.
- **Persistent Storage**: Integrated with MySQL using a high-performance connection pool.
- **Type Safety**: Fully typed with TypeScript for reliable development.
- **Prepared Statements**: Secure SQL execution using `mysql2/promise` to prevent SQL injection.
- **Filtering**: Query parameters to filter todos by completion status.

## 🛠️ Tech Stack
- **Runtime:** Node.js
- **Framework:** Express.js
- **Language:** TypeScript
- **Database:** MySQL
- **Driver:** mysql2

## 📋 Prerequisites
- [Node.js](https://nodejs.org/) (v18+ recommended)
- [MySQL Server](https://www.mysql.com/)
- npm or yarn
